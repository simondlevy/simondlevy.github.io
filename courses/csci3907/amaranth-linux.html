CSCI 3907: Installing Amaranth for FPGAs on Linux


  1. python3 -m venv csci3097-venv

  2. source csci3097-venv/bin/activate

  3. pip install amaranth

  4. pip install amaranth_boards

  5. sudo apt install yosys

  6. From this page, download and extract the oss-cad-suite-linux file for the processor on your machine (x64 or arm64).

  7. source oss-cad-suite/environment
