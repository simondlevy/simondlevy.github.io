CSCI 3907: iCEBreaker setup on Mac OS X



  1. Download the Bambu app image

  2. Right-click on the downloaded AppImage file and rename the file to simply bambu

  3. Right-click on the renamed bambu file, choose Permissions, and click on the checkbox to allow executing the file as a program

  4. Add the following two lines your ~/.zshrc file based on where you downloaded the Bambu app image and the OSS CAD suite. For example, if they're on your desktop:

    export PATH=$PATH:$(HOME)/Desktop/oss-cad-suite/bin
    export PATH=$PATH:$(HOME)/Desktop
