CSCI 3907: FPGA Quickstart with Amaranth



  1. Make sure you've installed Python on your computer and can run commands on the command-line (shell, terminal). If you haven't done this before or you run into trouble, ask me for help.

  2. In a terminal, run the command python3 -m pip install amaranth amaranth_boards

  3. On this page find the oss-cad-suite- .tgz file corresponding to your operating system and processor (note that Darwin is the official name for Mac OS X). Download and extract this file.

  4. Click on one of the following three links to complete the installation for your operating system:
    Mac OS X    Windows    Linux

  5. Plug your iCEBreaker board into your computer with a USB cable.

  6. Download and run this Python script to program your iCEBreaker board and see it blink an LED -- the hardware equivalent of the classic Hello World program.
