CSCI 3907 Assignment #1

For this assignment you will be modifying your C++ shape code from last week in the following ways:

  1. No explicit memory allocation;i.e., no new or delete

  2. No inheritance

  3. No mutation

  4. All variables declared const
What to submit

You should submit everything needed, and only what's needed, including a Makefile, for me to to run your program as follows (where $ represents the command-line prompt):

$ make run
