CSCI 3907: FPGA Quickstart with iCEBreaker



Option A: Install the toolchain on your laptop

Google oss cad suite install                , filling in the blank with the name of your operating sytem (mac os or windows or linux) and follow the directions in the AI-provided answer, raising your hand if you get stuck.

Option B: Use the toolchain installed in our labs

Log into one of the computers in our classroom, open a terminal window, and copy/paste/enter the following line:

echo -e "\nexport PATH=\$PATH:/opt/csci3907/oss-cad-suite/bin" >> ~/.bashrc

Checking your toolchain setup

Close the terminal window, open an other terminal window, and run the following command to check that your toolchain setup worked as expected:

yosys --version

Team exercise

  1. Google icebreaker fpga yosys blinky example to find a nice AI solution to making a “blinky” for your iCEBreaker board (blinky being the hardware equivalent of the beloved HelloWorld program). Copy/paste the code into the specified files (.v file and .pcf file)

  2. Once you can build and run the code on your iCEBreaker, do one of the following, based on your OS:

    • Mac OS or Linux: turn the Build and Flash commands into a little Makefile, following the process we've been using in class. Your Makfile should work as follows:

      Typing make should build the .bin file
      Typing make flash should load the .bin file onto the board, causing the LED to blink
      Typing make clean should delete everything but the .v file, .pcf file, and Makefile

    • Windows: the simplest way to pack everything into a single build-and-load script would probably be a traditional .BAT file, but perhaps you can take a more modern approach with VSCode, as appears to be supported by this repo.


  3. Once everything is working as specified, call me over for a demo!

Submitting to github:

Pick one member of your team to submit the code and send me an email asking me to check it. Your upload should include:

  • Your Verilog source file (.v)
  • Your Physical Constraints File (.pcf)
  • Your Makefile (OS X, Linux) or Windows equivalent (.BAT file or VSCode project)
  • A little README.md naming the members of your team, followed by instructions on how to run your code
