CSCI 3907: Installing Amaranth for FPGAs on Windows

As ever, if you have difficulty with any of the following steps, ask me for help:

  1. Edit the system environment variable PATH to include the bin and lib subdirectories of the oss-cad-suite directory that you just installed.

  2. Plug your iCEBreaker FPGA board into your computer with a USB cable.

  3. Download the Zadig USB driver tool and run it to install the driver for the iCEBreaker board.
